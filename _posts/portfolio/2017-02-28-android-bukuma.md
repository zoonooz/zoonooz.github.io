My second application in Japan was [ブクマ](https://xn--pck0dza.com/) (Bukuma) for Android.

**ブクマ** is a marketplace application that allows users to buy and sell books. Users can quickly find existing books by scanning the ISBN or easily create a new listing in the app. They can keep track of ongoing transactions and delivery status, talk to sellers or buyers via built-in chat, and use the review system to help them decide.

![image](/img/portfolio/bukuma.png)
{: style="text-align: center"}

The app was built with **Kotlin** as the main language, along with popular libraries like Dagger2, RxJava, and Retrofit.
